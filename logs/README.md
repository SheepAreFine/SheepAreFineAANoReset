# Your runs go here

The easiest way to add runs is **+ Add run** on your site (see the main README). It saves them here for you.
To do it by hand instead:

Put each run's Hermes `play.log` here, renamed to the run number: `1.log`, `2.log`, `3.log`, …

For elytra distance, also add that world's `stats/<uuid>.json` renamed to match: `1.stats.json`.

You can delete this file once you've added a run.
